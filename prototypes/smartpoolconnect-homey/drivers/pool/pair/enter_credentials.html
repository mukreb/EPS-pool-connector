SmartPoolConnect supports two credential types. An API key (spc_...) is recommended for permanent use and is issued by your pool installer or by api-support@smartpoolconnect.eu. An access token is a temporary fallback taken from a browser session — it works today but expires unpredictably; use the repair flow to paste a new one when it does.

Easiest: log in to smartpoolconnect.eu, open DevTools → Application → Cookies → smartpoolconnect.eu, and paste the full connect_session value here as-is — this app extracts the token from it for you. A bare access token works too, if you already have one. Not a standard JWT, so its expiry date can't be shown in advance.
Leave default unless SmartPoolConnect tells you otherwise.
